# Docker Skill Knowledge Graph

- **docker.input-isolation** — A stage receives only inputs that can affect it.
- **docker.late-revision-identity** — Add revision identity at its latest consumer.
- **docker.buildkit-authority** — BuildKit owns cache validity and reuse.
- **docker.real-cache-evidence** — Cache changes use cold, warm, import, and export builds.
