# Documentation Styles

Google's Spacing rule is copied unchanged from
[Google v0.7.1](https://github.com/vale-cli/Google/tree/v0.7.1).
Its [license](LICENSE.Google) is included. The small selection is shipped with
the framework, so initialization and checks do not download style packages.
Vale supplies the repetition check; Cortex owns only its product-name spellings.

## Update the selected rules

1. Review the upstream release and its rule changes.
2. Replace the selected file and preserve the license.
3. Run the documentation checks and their fixtures.

**Prohibited:** modify Google's copied rule to hide a finding.

**Preferred:** fix the prose; adopt upstream changes with the pinned source
reference and regression fixtures updated together.
