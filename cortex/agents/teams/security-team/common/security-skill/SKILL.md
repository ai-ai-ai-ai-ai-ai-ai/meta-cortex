# Common Security Skill

For work involving credentials, private keys, recovery material, or decrypted
payloads, read and apply [secret lifecycle](practices/secret-lifecycle.md).
It defines ownership, storage, redaction, lifetime, and cleanup requirements.

These requirements are language independent. They do not depend on any agent,
team, or specialized skill. Apply them to the consuming project's code and
validation evidence.
