# Cloud-Native Skill Knowledge Graph

- **cloud-native.scope** — Target the intended project, account, region, and resource explicitly.
- **cloud-native.current-state** — Read current state before a mutation.
- **cloud-native.secret-lifecycle** — Use approved identities and external secret storage; redact output.
- **cloud-native.recovery** — Prefer scoped, reversible changes when practical.
- **cloud-native.live-verification** — Verify required live state after a mutation.
